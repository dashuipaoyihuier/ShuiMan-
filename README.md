# 水漫 · 本地漫画阅读器

[English](README.en.md) · [开源说明](docs/OPEN_SOURCE.zh-CN.md)

水漫（ShuiMan）是一款以隐私和离线阅读为优先的本地漫画阅读器。目前提供 macOS 与 Android 版本，支持在设备上直接阅读用户合法拥有的图片、PDF、EPUB，以及其他逐步完善中的本地漫画格式；项目不提供、分发或索引任何漫画内容。

它面向那些在意阅读顺序、双页跨页和本地文件掌控感的读者：EPUB 以 spine 顺序为准，阅读方向和双页位置可分别调整；对横置跨页及相邻双图跨页提供保守的自动分析，并始终保留逐页手动纠正。阅读进度、书签和显示偏好只保存在本机，原始文件不会被修改。

## 特色：智能大跨页

水漫将大跨页作为核心阅读体验：遇到已确认的横向跨页时，画面会独占显示并完整适配；对两张相邻图片构成的跨页，会结合接缝、物理左右位置与阅读顺序做保守分析、自动组合。对于竖着存储的横向内容，应用还会结合出版物样式和文字方向线索建议转正。自动判断始终可以被手动旋转、配对、交换左右、取消或恢复，且手动修正优先于后续分析；无字、少字或接缝不明显的页面仍可能需要人工确认。

macOS 端基于 Swift、SwiftUI 与 AppKit，Android 端基于 Kotlin 与 Jetpack Compose；Windows 版本已列入计划，尚未确定实现与发布日期。项目在开发者主导下，借助 **OpenAI Codex** 协作实现、测试和迭代。

当前版本 **0.5.0**，macOS 面向 Apple Silicon、部署目标 macOS 14+；本次在 macOS 15.7.3 验证。

本项目以 [Apache License 2.0](LICENSE) 发布。

水波主题封面与蓝绿 UI 说明见 [水漫设计与安装](docs/水漫设计与安装.md)。

## 直接运行

双击 `build/水漫.app`。打开后用 **⌘O** 选择漫画或图片文件夹，也可以拖入窗口。书库保存最近阅读，点击书籍可接着读。

## 自动转正改进（0.4.2）

整页文字识别不足时，提取浅色对白区域并重排竖排字格，再将实际笔画与四个方向的字形模板比较。多个不同位置的字形共同决定朝向，避免把正常竖排文字误当成侧转文字。判断不依赖是否为跨页，也不依赖文件名或页码；确定横放后自动旋转并完整适配。

公开回归使用原创夹具；这不代表跨书漏检率或准确率。无字、浅色对白区域不足、特殊手写字体仍可能漏转。

## 沉浸阅读与全屏

打开漫画后默认显示阅读控件，包括顶部工具栏、翻页栏，以及按原偏好显示的缩略图侧栏；不再自动进入沉浸模式。底部主导航仍用于书库。按 **Tab** 或 **⌘⇧H** 显示/隐藏阅读控件；鼠标移到画面右上角也能唤出入口。输入框编辑时 Tab 保持正常焦点切换。

**⌃⌘F** 进入/退出系统全屏。进入全屏自动收起阅读控件，退出后恢复进入前的显示状态；书库仍保留底部四项导航。画面右键菜单也提供控件、全屏和返回漫画库。窗口模式隐藏控件后按 Esc 可显示控件。

沉浸画布去掉额外 24 点留白；图片与屏幕比例不同时仍保留必要黑边，以完整显示漫画。系统菜单可在屏幕顶边按 macOS 行为临时唤出。

## 漫画库与底部导航

窗口最下方固定四个入口，与阅读画布的翻页工具栏分开：

- **阅读**：当前书籍或最近阅读；切换到书库再回来不会丢失当前页面。
- **浏览**：按目录建立系列，点系列进入卷列表；支持名称/标签搜索、阅读状态过滤及卷列表网格/紧凑显示。
- **标签**：收藏和自定义标签筛选。每卷“编辑”可改卷名、系列、卷号、标签与阅读状态；同名手动系列可合并，版本不同请用不同名称。
- **导入**：添加包含 EPUB/PDF/图片文件夹的目录，递归索引；启动时及运行中每分钟刷新，也可手动更新或停止扫描。原漫画不复制、不改写。

读到末尾会出现“阅读下一卷”；首次打开下一卷沿用当前阅读偏好，已有阅读记录则优先恢复该卷设置。文件暂时缺失时保留进度，下一卷缺失不会自动跳过。图片文件夹作为一卷；与 EPUB/PDF 混放的散落图片视作封面素材，不额外建立书卷。符号链接和隐藏目录跳过。

0.4 使用新书库表保存元数据，沿用现有阅读记录；封面按需提取并保存在系统缓存目录。文件移动后的自动重新关联仍未实现，旧路径保留为不可用。

## 当前可用

- 图片/图片文件夹自然排序；PNG、JPEG、TIFF 等由系统 ImageIO 解码；多页 TIFF 展开、GIF 取首帧。
- PDF 逐页读取、密码输入；EPUB 按 spine 读取，复杂图文页面使用 WebKit 原版式视图。
- 单页/双页、左右阅读方向、缩略图、目录、跳页、全屏、窗口/宽度适配、缩放和拖动。
- 横图完整适配；Vision 文字框方向辅助转正；保护常见竖排文字和短装饰词。
- 相邻图片接缝分析、自动左右推断、等比例缩放与竖直对齐；默认积极自动合并，可关闭“积极合并”回到保守模式。
- 手动旋转、配对、交换左右、取消、恢复自动识别；当前页显示后不会被迟到分析突然翻转或重新配对。
- EPUB 旋转样式按实际选择器、常见优先级、内联和 `!important` 提取；过滤打印条件。复杂页面继续交给 WebKit。
- 本地 SQLite 保存位置、书签、每本书偏好及页面修正，不改写原漫画。

| 操作 | 入口 |
| --- | --- |
| 打开 | ⌘O |
| 返回书库 | ⌘⇧L |
| 翻页 | ← / → 遵循阅读方向；画布获焦后空格下一组、⇧空格上一组 |
| 旋转 | R 顺时针、⇧R 逆时针，或右上角“…” |
| 组合双图 | 定位到两张图中来源顺序较早的一张 → “…” → 与下一页组成跨页；必要时交换左右 |
| 取消配对 | “…” → 取消跨页配对；重新打开后仍然有效 |
| 恢复识别 | “…” → 清除当前页修正，恢复自动识别 |
| 关闭自动双图 | “…” → 自动合并双图；手动确认的配对仍保留 |
| 书签 | ⌘D 或底栏书签图标 |
| 完整适配 | ⌘0；底栏可切换适合宽度 |
| 缩放/移动 | 底栏 ±、触控板捏合、双击画面；放大后拖动 |

旧版已手动确认的配对仍优先使用原修正。想更新其对齐，可在该组选择“…” → **自动校正左右与接缝**。自动转正独立于智能跨页开关，普通横置单页也能转正后完整放大适配窗口。

## 构建与回归

本机已用 **Apple Swift 6.2.3 Command Line Tools** 构建原生 `.app`，不要求先安装完整 Xcode。工程只维护 SwiftPM 配置。首次构建需要网络下载精确锁定的依赖：ZIPFoundation 0.9.20、SwiftSoup 2.6.0、GRDB 7.0.0。

```bash
cd <仓库目录>
scripts/build.sh             # release，生成 build/水漫.app
scripts/build.sh debug       # 调试构建
scripts/test.sh              # 生成原创样本并运行原生核心检查
open build/水漫.app
```

日志在 `.build/build-release.log`、`.build/build-debug.log`。本轮检查覆盖原创图片/PDF/EPUB 2、EPUB 3 样式用例、自动配对与对齐。Vision 在受限执行环境可能不可用；`--analyze` 的方向检查须在本机普通终端执行。这些是自定义 Swift 检查和实际窗口验收，没有声称 XCTest/XCUITest 覆盖。

私有漫画语料不随项目发布；公开回归使用仓库内可重建的原创夹具。

原创测试资料位于 `Tests/Fixtures/`，由 `Sources/ReaderChecks/Fixtures.swift` 重建。包括六张图片、三页 PDF 及密码/旋转元数据变体、五个 spine 单元 EPUB 和切分跨页真值。`Protected.pdf` 的测试密码是 `comic-test`。用户提供的漫画不纳入版本管理。

## 版本管理

仓库保存源码、开发文档、依赖锁定与原创样本生成器。用户文件、生成的测试媒体、应用包、构建缓存及阅读数据库由 `.gitignore` 排除。克隆后运行 `scripts/test.sh` 会重新生成测试文件。

```bash
git status                    # 查看当前修改
git log --oneline --decorate   # 查看提交与版本标签
git diff                      # 查看尚未暂存的改动
git switch -c feature/功能名   # 为下一项功能建立分支
```

后续较大功能使用独立分支，完成相应验证后按功能提交，`main` 保留可运行版本。提交前请为本仓库配置自己的 Git 署名。

## 原型边界

**仍是需要纠错入口的原型。** 自动转正依赖可读文字或出版物线索，无字/少字页会漏识别；原生竖排 CJK 与部分侧转文字难以区分时保持原样。双图默认积极合并，但朝向不明确、接缝纹理少或相邻配对冲突时仍可能漏检。当前样本集中只有两种 CSS 模板，不能据此宣称通用准确率。所有置信数值都是启发式分数，不是概率。

接缝校正目前覆盖等比例缩放和上下位移，不能保证弯曲纸张、倾斜扫描或缺失内容也严格吻合。完整图像均保留，包括扫描白边；暂不自动裁掉中缝或重建丢失内容。14 页原创 EPUB 3 样式用例不能代表完整 EPUB 3 合规；SVG、复杂固定版式和高级 CSS 仍依赖 WebKit。屏幕媒体条件用于提取可能的旋转提示，原生优化视图不模拟浏览器的完整媒体查询计算。

尚未实现整本连续滚动、完整 EPUB CSS/媒体条件语义、文字搜索、云同步、多选文件导入和放大后的超高分辨率重绘。当前主画面最大解码边长 3200 像素。HEIC/WebP/AVIF 等支持取决于系统解码器，未逐一做格式验收。

应用数据保存在系统的应用支持目录。书籍身份目前基于路径；移动文件后的关联、App Sandbox 和长期数据库升级仍需完善。当前构建尚未进行 Developer ID 公证，未验收其他 Mac、Intel 或 macOS 14。
