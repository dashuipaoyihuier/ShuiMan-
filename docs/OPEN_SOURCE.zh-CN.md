# 水漫开源说明

[English](OPEN_SOURCE.en.md)

## 项目范围

水漫是离线、本地优先的漫画阅读器。公开仓库包含 macOS 与 Android 的源码、构建脚本、依赖锁定、原创测试夹具和必要的产品/技术说明。Windows 处于计划阶段，暂不承诺技术路线或发布日期。

代码以 [Apache License 2.0](../LICENSE) 发布。第三方依赖与通知见 [ThirdPartyNotices.txt](../Resources/ThirdPartyNotices.txt)。

## 公开仓库可以包含的内容

- 源码、资源、构建脚本与依赖锁定文件。
- 可公开的设计与实现文档。
- 由测试代码重新生成的原创夹具、标签与测试说明。
- 不含个人数据的构建/测试说明。

## 不得提交的内容

- 漫画、电子书、封面、扫描页或任何其他受版权保护的用户内容。
- 本地书库路径、书目、阅读记录、书签、数据库、日志、截图和分析结果。
- 签名证书、密钥库、令牌、账号、设备标识、个人邮箱或绝对本机路径。
- APK/AAB、应用包和其他可再生成的构建产物。

`.gitignore` 已覆盖常见书籍格式、应用数据、签名材料、构建目录和私有验证记录；提交前仍应运行 `git status --ignored` 进行人工复核。

## 构建入口

```bash
scripts/build.sh
scripts/build.sh debug
scripts/test.sh
```

Android 工程位于 `android/`。公开测试只使用 `Tests/Fixtures/` 中可重建的原创夹具；不要使用个人语料作为提交或发布验证证据。

## 发布原则

- 发行包不得包含用户内容、阅读数据库或签名私钥。
- macOS 公布发布包前应完成目标系统验证、Developer ID 签名和公证。
- Android 公布发布包前应使用受控的发布签名流程，并保留签名材料在仓库外。
- 自动跨页、转正和配对是启发式功能；发布说明应说明其边界，且不得宣称未经公开、可复现评测支持的准确率。

项目由开发者主导，并借助 OpenAI Codex 协作实现、测试与迭代。
