# 水漫 Windows 0.7.0

这次更新重做了 Windows 书库与阅读界面，并提供可直接双击安装的 Windows 安装包。EPUB 图片漫画统一使用原生画布，和 ZIP、PDF 一样支持旋转、跨页与手动修正。

## 下载与安装

- **推荐安装版：`ShuiMan-Setup-0.7.0-x64.exe`**。中文安装向导，默认安装到当前用户，创建开始菜单快捷方式；桌面快捷方式和“打开方式”入口可按需选择。
- Release 附件只收录三个平台的安装包：Windows **`ShuiMan-Setup-0.7.0-x64.exe`**、Android **`Shuiman-1.0.5-android-release.apk`** 和 macOS **`Shuiman-0.6.0-macOS-arm64.zip`**，保留各平台原版本名。
- Windows 免安装 ZIP 与 SHA-256 文件由构建脚本和 Windows 工作流生成。便携包完整解压后，打开 `ShuiMan` 文件夹并运行 `ShuiMan.exe`。
- Windows 支持 **Windows 10 2004（19041）及更新版本、Windows 11，x64**。Windows 安装版和本地构建的便携版都包含 .NET 与 PDF 阅读所需组件，安装和阅读无需补装浏览器运行时。
- GitHub 自动提供的 “Source code” 附件是源码，不是可运行的应用安装包。

## 本次更新

- **重新设计书库**：采用接近 macOS 阅读应用的简洁布局、柔和配色与封面卡片。默认先按系列浏览，进入系列后优先提取原文件名中的卷号，再按显示书名自然排序，避免卷 10 排在卷 2 前面。保留搜索、收藏、阅读状态、标签编辑、封面网格与详细列表。
- **统一应用图标**：窗口标题、任务栏、程序和安装器使用 macOS 原版书页与水波图形。保留原始图标表示，并补齐 Windows 所需的不同缩放尺寸。
- **完善书库管理**：支持批量导入和拖入文件或目录，可添加漫画来源目录并刷新扫描；继续阅读、书库与阅读视图之间切换更直接。阅读进度与书籍信息分别保存，避免旧的阅读状态覆盖刚修改的书名或标签。
- **EPUB 全原生图片阅读**：按出版物 spine 顺序提取漫画图片，保留重复引用和缺失页面位置。移除网页排版模式与 WebView2 依赖，恢复图片页的旋转、配对和接缝修正操作。纯文字内容不会交给浏览器显示。
- **逐页识别，立即应用**：打开书籍后从当前阅读位置向后扫描，再补齐前面的页面。每页方向与相邻接缝完成后立即生效，当前画面会自动更新；绘制期间到达的新结果也会自动补绘，无需额外点击。后台显示进度并保存本地缓存，再次打开复用结果、继续未完成的扫描。
- **遵循 EPUB 方向信息**：手动修正 → 当前页明确的 EPUB 旋转标记（包括 0°）→ 无标记时自动识别。关闭自动识别仍遵循出版物标记。无标记页使用参考 macOS 实现的 CJK 字形方向证据；低置信度内容保留人工纠正入口。
- **补齐双页与双图跨页**：普通双页显示相邻两页并保留中缝；智能双图根据接缝连续性、方向和相邻竞争关系组合成完整画面。与 macOS 一样默认启用积极识别，也可切换严格判断。图像缩小使用面积抗混叠，接缝轮廓使用轻量平滑，减少网点纹理的干扰；保留原有接受阈值。
- **正式 Windows 安装器**：支持当前用户安装、覆盖升级和 Windows“已安装的应用”卸载。已有 0.6.0 脚本安装目录可直接升级；升级和卸载保留原漫画、书库与阅读记录，不抢占 ZIP 等文件格式的默认程序。
- **继续支持 ZIP/CBZ**：直接读取压缩包中的图片，支持中文路径、嵌套目录及自然数字排序，无需先解压漫画，也不修改原文件。

## 升级说明

关闭正在运行的水漫，再运行新版安装包。默认程序目录为 `%LOCALAPPDATA%\Programs\ShuiMan`；书库和阅读记录仍保存在 `%LOCALAPPDATA%\ShuiMan`。便携版请完整解压新版程序文件后运行。

## 验证

本轮包含新跨页算法的 Release 构建通过 **71 项核心回归、65 项原生界面检查，0 项失败**，其中包含 16 项后台分析、异步边界与增量应用窗口检查。安装器此前已通过 **23 项独立安装、覆盖升级和卸载检查**，确认组件、快捷方式、文件关联及原漫画与书库保留；具体程序包与检查范围见[验证记录](../windows-validation.md)。

本轮跨页算法版本为 `seam-scale-offset-v4-antialias`。实际匿名样本 226 页、225 条接缝经完整布局规则得到 13 组，保留旧版的全部 6 组；前 50 页中的 3 组已查看合成图，连续性与物理左右正确。此前“4 册 17 组”属于 v3 历史取样，不是本轮结果。自动回归使用生成素材，不代表全部真实出版物和 OCR 条件均已覆盖。

## 已知范围

- EPUB 面向图片漫画。纯文字页、无法提取图片的页面会保留阅读位置并显示提示；HTML/CSS 文字排版和脚本不执行。
- 自动转向依赖 Windows 可用的 OCR 语言与字形证据。字体、画质、文字数量及竖排内容会影响结果，不能承诺对全部中文或日文漫画自动转正；可使用手动旋转与配对。
- 不支持加密或分卷 ZIP、RAR/CBR、DRM 电子书、纯 KF8/AZW3、MOBI HUFF/CDIC，以及 MOBI 文字/混合排版。MOBI 支持范围为无 DRM 的旧版 MOBI 6 图片漫画。
- 动画图片按静态页面阅读；多页 TIFF 按独立页面阅读。大图解码最长边上限为 8192 像素，原图保持不变。
