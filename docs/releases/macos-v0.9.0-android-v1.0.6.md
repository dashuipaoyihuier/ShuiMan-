# macOS 0.9.0 / Android 1.0.6

日期：2026-11-09。

本轮从不含自动上色的跨平台主线继续开发。macOS 应用不包含云端或 Codex 上色入口，保留原有书库、进度、手动修正和 MOBI 阅读。既有上色数据与原漫画不删除。版本号保持递增，便于覆盖安装。

## macOS

- PDF 按每页有效 CropBox / MediaBox 交集与内置旋转确定尺寸，位图与页面索引使用一致的几何信息；阅读画布不额外添加四周边距。
- 阅读菜单新增默认开启的“PDF 自动裁白边”：仅裁页面外围近白区域，保留约长边 0.5% 的安全边距。关闭立即恢复完整页面，偏好按书保存。纯白页、只有小标记的页面保持原尺寸；已确认的双图跨页不分别裁切，以保护接缝。缩略图仍展示完整来源页面。
- 裁剪发生在后台渲染结果上，不改写 PDF。非常浅的内容和带底色、噪点的扫描页仍可能需要关闭裁剪；本轮没有取得问题报告中的原 PDF，验证使用原创样本。
- 新增 ZIP / CBZ 图片漫画：包内路径自然排序、嵌套目录、忽略隐藏资源、TIFF 多帧、损坏页保位、路径与帧号稳定定位。无需先解压，书库扫描和 Finder 打开方式可识别。包内再套 ZIP 或电子书不自动递归打开；加密 ZIP 不支持。

## Android

- 支持无 DRM 的 MOBI 6 图片漫画及双格式文件中的 MOBI 6 正文，包含未压缩与 PalmDOC 压缩。按正文 recindex 保序，保留重复引用与缺图位置；未在正文出现的声明封面单独呈现。文件选择器允许通用文件类型，MOBI 可按扩展名、MIME 或 BOOKMOBI 签名识别，目录导入也可发现。
- 旧版本误当作图片的 `.mobi` 记录打开时可恢复为 MOBI；读书位置和用户元数据保留。纯 KF8、HUFF/CDIC、DRM、文字混排会明确提示当前限制。
- 默认音量减下一组、音量加上一组，方向不随 RTL/LTR 反转，长按不连翻；阅读设置提供开关。书库、设置面板、导航和纠错弹层不接管音量键。
- PDF 使用 PDFium 已处理有效页面边界和旋转的尺寸，修复缺少 CropBox 的旋转页面重复交换宽高。
- 封面保存到持久的应用目录；进入书库时后台修复未完成导入、旧缓存丢失或图片损坏的封面，并逐本刷新卡片。EPUB 优先读取声明封面，即使封面不在 spine 或正文需网页排版；失败时尝试其他可读页面。修复不改变原书顺序、书名、收藏、标签或阅读记录。加密且尚未解锁的 PDF、不可访问或不受支持的文件无法凭空恢复封面。
- 原有 ZIP / CBZ 阅读保留，并补上 `.zip` 扩展名实际导入、渲染、自然排序和原文件不改写的设备检查。

## Windows

现有 Windows 0.7.2 已支持 ZIP / CBZ。已核对文件选择器、拖入解析器、目录扫描、安装器“打开方式”关联和既有自然页序、嵌套目录、多帧、危险路径回归源码。本轮未修改 Windows 程序，也未在 macOS 上声称执行 WPF 原生测试；现有 Windows 安装包可继续直接打开 ZIP 图片漫画。

## 本地安装包

macOS：`build/水漫.app` 与 `build/水漫-0.9.0-macOS-arm64.zip`。
Android：`build/水漫-1.0.6-android.apk`，沿用已有发布签名，可覆盖同签名旧版本。

macOS 最终版已安装至 `/Applications/水漫.app`；原上色版与更新前版本保存在 `build/previous-version/`。两个安装包的校验值在 `build/reader-update-SHA256SUMS.txt`。

本轮没有推送分支或发布 GitHub Release。APK 安装后回到书库，给后台封面补全留出时间；大书库按书逐本恢复，无需删除书库或重新导入全部漫画。
