# Android 1.0.7：PDF 自动裁白边

日期：2026-11-09。补齐 Android 1.0.6 没有加入的 PDF 裁剪；macOS 0.9.0 / Windows 0.7.2 不变。

## 行为

PDF 阅读设置新增默认开启的裁白边开关，按书持久化。后台逐行扫描每个像素，保留外围近白区域以内的内容和约长边 0.5% 的安全边距；空白页和小于整页 3% 的孤立标记保持原尺寸。没有改写 PDF，也不改变原始页码、阅读位置和手动修正。

显示尺寸以裁剪区域在原页中的比例计算，再应用阅读旋转；画布、平移范围和滚动项高度同步更新。缓存包含裁剪状态，切换开关可立即恢复原页。已合并的双图跨页不分别裁切，保留接缝。底层文档渲染器继续返回完整页，所以封面、缩略图与跨页分析不受裁剪影响。

浅色内容、噪点和有底色扫描页仍可能需要关闭裁剪。范围与 Mac 0.9.0 一致，没有承诺所有扫描件都能消除全部白边。

## 验证

- 57 项 JVM 测试通过。
- 11 项专项设备检查通过：不对称白边、纯白页、小标记、浅色边缘文字、背景色、真实 PDF 渲染、旋转、原文件不改写、跨页保护、实际画面比例、重复切换开关与缓存、重新打开及旧偏好默认值。
- 32 项原有设备回归通过：原图尺寸、适宽、缩放平移、滚动位置恢复、翻页、封面实际显示、ZIP/MOBI、书库与导入状态、密码 PDF。与专项合计 43 项通过。
- Release 构建与 APK v2 签名验证通过，版本 1.0.7 / versionCode 8。
- Android 16 / API 36 ARM64 模拟器；没有安卓真机覆盖。本轮未修改或重测 Mac / Windows 程序。
