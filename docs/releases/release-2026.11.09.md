# 水漫 · 三端统一更新（2026-11-09）

本次统一收录最新的 macOS、Android 和 Windows 安装包，并汇总本轮全部更新。版本如下：

| 平台 | 版本 | 安装包 |
| --- | --- | --- |
| macOS · Apple Silicon | 0.9.0 | `Shuiman-0.9.0-macOS-arm64.zip` |
| Android | 1.0.7 | `Shuiman-1.0.7-android-release.apk` |
| Windows · x64 | 0.7.2 | `ShuiMan-Setup-0.7.2-x64.exe` |

## macOS 0.9.0

- 恢复不含自动上色的阅读版本，保留书库、阅读进度、书签和手动修正；不删除已有上色数据。
- PDF 按实际页面尺寸、裁剪边界和旋转方向自适应显示，去除阅读画布额外边距。
- 新增默认开启的“PDF 自动裁白边”，尽量放大漫画内容；可在阅读菜单关闭并恢复完整页面，偏好按书保存。
- 新增 ZIP/CBZ 图片漫画直接读取，无需手动解压；支持嵌套目录、自然数字排序、TIFF 多帧和损坏页面保位。

## Android 1.0.7

包含 1.0.6 的全部修复，以及新增的 PDF 裁白边：

- 新增“PDF 自动裁白边”，默认开启，在 PDF 的阅读设置中可关闭恢复完整页，开关按书保存。
- 裁剪后的内容按新宽高比例放大，画布、缩放平移范围和上下滚动的页面高度同步适配；修复部分旋转 PDF 的宽高比例错误。
- 支持无 DRM 的 MOBI 6 图片漫画及 PalmDOC 压缩，修复通用文件类型识别和旧书库的误识别记录。
- 支持音量键翻页：音量减下一组、音量加上一组，长按不连续翻页；可在阅读设置关闭，书库和设置面板保留正常音量调节。
- 修复封面缺失不恢复的问题：封面持久保存，进入书库后自动逐本补全，无需重新导入。支持 EPUB 独立封面，首张图片损坏时尝试其他可读页面。
- 保留 ZIP/CBZ 直接读取，并验证实际 ZIP 导入、自然页序和渲染。

## Windows 0.7.2

沿用已发布的 0.7.2 安装包，程序没有新增改动。现有版本已支持 ZIP/CBZ 直接读取、嵌套目录和自然数字排序，也保留 PDF、EPUB、MOBI 6 图片漫画阅读及 ↑ 键旋转功能。

## 升级与使用

- 三端均可直接读取 ZIP/CBZ 图片漫画。压缩包里的 ZIP 或电子书不递归打开，加密 ZIP 不支持。
- PDF 自动裁白边目前提供于 **macOS 0.9.0 和 Android 1.0.7**。保留少量安全边距；纯白页和只有小标记的页面保持原尺寸，已合并双图跨页保留接缝。特殊扫描页或非常浅的内容如显示不完整，可关闭裁剪恢复。
- 裁剪仅影响阅读显示，不修改原 PDF；原漫画、书库和阅读记录保留。
- 安卓 APK 沿用原发布签名，可覆盖同签名旧版。升级后进入书库，给后台封面补全留出时间，无需清空书库。
- MOBI 支持无 DRM 的 MOBI 6 图片漫画；纯 KF8/AZW3、HUFF/CDIC 和文字混排暂不支持。
